# Tài liệu để đội báo cáo hoàn thiện

Đã có tài liệu thiết kế, hướng dẫn chạy, hướng dẫn đo và bảng đối chiếu ảnh.
Chúng không thay cho báo cáo Word/PDF cuối 20–40 trang khuyến nghị của đề.

Đội báo cáo đặt báo cáo cuối (docx hoặc pdf) vào thư mục docs này, đủ chín
mục theo đề. Dùng THIET_KE.md để dựng sơ đồ kiến trúc, sơ đồ lớp và ít nhất
hai sơ đồ tuần tự/hoạt động. Trích số đo thật, ghi rõ phạm vi và số lượt đo.
Dẫn nguồn đúng IEEE/APA, phân công/tỷ lệ đóng góp do nhóm tự xác nhận.
